# Kibana Dashboards

This document describes the dashboards created in Kibana to monitor, analyze, and investigate security events generated by the intrusion detection platform.

The dashboards transform raw network events into meaningful visualizations, enabling rapid detection of suspicious activity and supporting incident analysis.

# Overview

Kibana serves as the visualization layer of the platform.

All alerts generated by Suricata are forwarded to Elasticsearch through Logstash and become immediately available for visualization and investigation.

The dashboard provides analysts with a centralized interface to monitor network activity, identify attack patterns, and review security events in real time.

---

# Dashboard Objectives

The dashboards were designed to:

- Monitor security events in real time
- Identify the most frequent attacks
- Detect abnormal network activity
- Investigate suspicious hosts
- Analyze attack trends
- Simplify incident response

# Dashboard Filters

Analysts can filter events by:

- Source IP
- Destination IP
- Protocol
- Signature
- Severity
- Time Range
- Destination Port

Example

```
Source IP

=

192.168.100.30
```

This displays only events generated by the Kali attacker.

---

# Threat Hunting Example

Scenario:

Investigate an SSH brute-force attack.

Filter:

```
Signature

contains

SSH
```

Results:

- Source IP
- Number of attempts
- Timestamp
- Destination Host
- Alert Priority

The analyst can then determine whether the activity is legitimate or malicious.

# Dashboard Performance

Recommended settings:

- Refresh Interval: 30 seconds
- Time Window: Last 15 minutes
- Index Lifecycle Management enabled
- Automatic index rollover

# Dashboard Summary

The Kibana dashboards provide a centralized and intuitive interface for monitoring the security posture of the laboratory environment.

By combining metrics, charts, and event tables, the dashboards enable analysts to quickly identify malicious activity, investigate incidents, and evaluate the effectiveness of the intrusion detection platform.

The dashboards also demonstrate the practical value of integrating Suricata with the Elastic Stack to create a lightweight Security Information and Event Management (SIEM) solution suitable for educational, research, and small-scale enterprise environments.
